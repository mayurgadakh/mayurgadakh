## Featured Project: DocUp (AutoDocs)

<div align="center">
  
### **[docup.dev](https://docup.dev)** - AI-Powered Documentation-as-a-Service

</div>

**The Problem:** Developers spend hours writing and maintaining documentation. Outdated docs lead to confusion and wasted time.

**The Solution:** DocUp automatically generates structured, searchable documentation from GitHub repositories using AI.

<table>
<tr>
<td width="50%">

### Key Features
- **Automatic Doc Generation** from GitHub repos
- **AI-Powered Search** with semantic understanding
- **Multi-Tenant Architecture** with isolated environments
- **Real-time Updates** when code changes
- **Custom Domain Support** for each project
- **MDX-based Documentation** with rich formatting

</td>
<td width="50%">

### Technical Architecture
- **Embeddings Pipeline** for large-scale repo indexing
- **Chunking Strategies** for optimal context retrieval
- **Parallel Workers** for high-throughput processing
- **Row-Level Security (RLS)** via Supabase
- **Domain-Level Sandboxing** for tenant isolation
- **Vector Search** powered by Qdrant

</td>
</tr>
</table>

**Tech Stack:**  
`Next.js` `TypeScript` `LangChain` `OpenAI API` `Qdrant (Vector DB)` `Supabase (PostgreSQL)` `MDX` `Vercel` `Multi-tenant SaaS Architecture`

**Impact:** Reduces manual documentation effort by 80%+ for development teams.

> **Why This Matters:** Built a production-grade RAG system that handles repository parsing, intelligent chunking, vector embeddings, and semantic search — all while maintaining strict tenant isolation and security.
